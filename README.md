what it is, and why you made it?

This is a project called Starbie even though the shape doesn't look like a star... In a nutshell, This is a tamagotchi.  I made this project for me to learn about PCB Design, soldering and how hardware communicate.

How it works: how the parts fit together.

I used multiple hardware as I shown at BOM. The XIAO ESP32 C3 will be the microprocessor where it will run the code, 0.96 OLED is to show the character. MPU6050 is a sensor to detect movement, when you move the board around something will happen. DHT11 is also a sensor which detect temperature, so you could use the temperature data and then the character could ask you to drink more water. MX Switches is the button to interact with the project. Keycaps is for the switches so it feels comfortable to click it. 10k Resistor is used to prevent too much voltage from entering it without this, the circuit will explode. For PCB printing I just used JLCPCB to print it.
